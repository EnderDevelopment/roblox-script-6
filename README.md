# Roblox Scripts

This project provides a collection of useful scripts for Roblox games, including a rotating cube, an invisible hitbox, and a rounded square menu. These scripts are designed to enhance gameplay and provide additional functionality for Roblox developers.

## Install

1. Clone the repository to your local machine using the following command:
   ```
   git clone https://github.com/yourusername/roblox-scripts.git
   ```
2. Navigate to the project directory:
   ```
   cd roblox-scripts
   ```
3. Copy the desired script from the `scripts` directory to your Roblox project.

## Use

1. Open your Roblox Studio.
2. Create a new project or open an existing one.
3. Drag and drop the script into the appropriate service in the Explorer window:
   - For the rotating cube script, place it in the Workspace service.
   - For the invisible hitbox script, place it in the StarterPlayerScripts service.
   - For the rounded square menu script, place it in the StarterGui service.
4. Run the game to see the script in action.
